pokered Map Editor

Blocks (drag onto map, or click to select then paint)

Categories are derived from this repo's real collision/water/ledge/door/grass data per tileset — a best-effort split, not hand-curated, so a few blocks may land somewhere unexpected.
Select mode on the map: drag to select, shift+drag adds, alt+drag removes. Fill/erase the selection, or (if it's a solid rectangle) save it as a stamp.

Stamps (houses / buildings)

Warps / doors / entrances

Switch to Warp mode and click a block to place a door there. X/Y are in tile units (each block = 2×2 tiles), defaulted to the block's bottom-right tile; nudge by 1 if your door art sits elsewhere in the block. Warp id is which entry in the destination map's own def_warps_to list you land on.

Map connections

OnTarget mapOffset
Offset shifts alignment between maps of different sizes, same as pokered's connection macro. You still need the target map to exist separately.

Export for the disassembly

This tool only generates block layout, warps, and connections. You'll still need to register the map in constants/map_constants.asm, data/maps/maps.asm, map_header_pointers.asm, map_header_banks.asm, and wire up any signs/NPCs/wild data by hand.
